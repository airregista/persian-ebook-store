## وابستگی‌ها و منطق تقدم (Dependency Notes)

1. **پلن 001 پیش‌نیاز همه پلن‌هاست:** تعریف توکن‌های رنگی، فونت فارسی وزیرمتن، حالت راست‌چین (`dir="rtl"`) و پیکربندی ابزارهای اساسی Shadcn (`cn`، دکمه، نشان، کارد، دیالوگ و ...) است تا تمام کامپوننت‌های بعدی از سبک یکنواخت استفاده کنند و کامپوننت سفارشی دلبخواهی ساخته نشود.
2. **پلن 002 پیش‌نیاز ویترین (003):** لایه داده باید مدل‌های مشخص (`Book`, `AudioBook`, `Review`) و یک مسیر API امن با مکانیزم Fallback داشته باشد تا صفحه اصلی داده واقعی فیدیبو را نمایش دهد و در صورت آفلاین بودن یا قطعی موقت فیدیبو، سایت هرگز بدون محتوا نماند.
3. **پلن 003 پیش‌نیاز پلن 004:** کامپوننت مشترک کارت کتاب (`BookCard`)، قفسه‌ها و ساختار صفحه در این مرحله کامل می‌شوند.
4. **پلن 004 پیش‌نیاز پلن 005:** باز کردن کتابخوان یا پلیر صوتی مستقیماً وابسته به داده‌های کتاب و وضعیت خرید کاربر (در LocalStorage) است.
5. **پلن 006 مرحله پایانی:** تطبیق دقیق با راهنمای طراحی رابط وب Vercel (Web Interface Guidelines)، بررسی کنتراست رنگ‌ها، ناوبری کیبورد و تست نهایی بدون باگ بیلد.

## موارد بررسی‌شده و رد شده (Considered and Rejected)

- **استفاده از دیتابیس خارجی یا سیستم احراز هویت (Auth/DB):** طبق دستور صریح کاربر و صورت‌مسئله، هرگونه بک‌اند دیتابیس یا فرم لاگین رد شده و داده‌های کاربری (علاقه‌مندی‌ها و کتابخانه خریده‌شده) منحصراً در `localStorage` کلاینت مدیریت می‌شود.
- **ایجاد کامپوننت‌های دلبخواهی و بدون استاندارد:** به جای ساخت دیالوگ‌ها یا کارت‌های دستی با `div`، строго تمام المان‌ها از کامپوننت‌های پایدار `shadcn` مشتق می‌شوند.
- **اتصال درگاه بانکی واقعی:** صرفاً شبیه‌سازی خرید موفق همراه با بازخورد بصری و باز شدن قفل مطالعه برای سادگی و سرعت تست بدون خطا.
